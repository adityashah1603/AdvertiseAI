# Patagonia (test brand) Design Brain

What a customer's brand looks like inside CharacterQuilt - synthesized from
public research rather than a customer submission.

| | |
|---|---|
| `DESIGN.md` | The brand. Palette, type, scale, shape, voice, and a Provenance section explaining what is documented fact vs. an inferred/substituted judgment call. |
| `fonts/` | Public Sans (SIL OFL), standing in for Patagonia's real (proprietary, unbundleable) typefaces. |
| `brand/asset_manifest.json` | Staged logo and media paths, with the kit id. |
| `brand/tokens.json` | A cached export from brand-sync. |

Inspirations are not in here. They ship separately.

This brain exists to stress-test the pipeline against a brand with a very
different visual language from Emplifi (SaaS, navy/periwinkle, rounded,
Inter) and Kahua (construction, navy/orange, sharp, Barlow/Barlow Condensed):
earthy and square-cornered, photography-led, with a single restrained accent
and a near-zero color palette. Its logo and mark are original placeholders,
not the real Patagonia trademarks - see `DESIGN.md`'s Provenance section.
