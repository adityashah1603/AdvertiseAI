# Kahua - Design Brain

Source of truth for brand tokens. Where any manifest, cache or prior asset
disagrees with this document, this document wins.

Last reviewed: 2026-06-30

## Palette

- primary: #1B3A5C
- accent: #F26B21
- surface: #FFFFFF
- ink: #16202B
- muted: #6B7A88

## Type

- heading: Barlow Condensed
- body: Barlow

## Type scale

- h1: 56px
- h2: 36px
- h3: 24px
- body: 17px
- caption: 14px

## Shape

- border-radius: 4px

## Applying it

Kahua is construction project management. Tone is plain, operational and
confident. Avoid startup-speak, exclamation marks and abstract gradients.
Photography is jobsite-real, never stock-office.

Headline type is Barlow Condensed 700, set tight. An h1 is 48px on every
canvas. If the headline does not fit at 48, cut the copy; do not scale the
type. Body copy is Barlow 400, and the eyebrow above a headline is Barlow 600
at caption size, letterspaced, in the accent.

The accent carries the call to action and almost nothing else. A primary
button is a solid fill of Kahua orange, #F26B21, with white label text at
Barlow 600. Secondary buttons are a 1px #F26B21 outline on surface with the
label in the same orange. Never tint the accent, and never use it as a
background for a region larger than a button.

Cards, modals and image containers use the 4px corner. Buttons and inputs use
the same. The radius is deliberately small; Kahua should read as a tool, not a
consumer app.

Charts run primary to accent. Never introduce a hue that is not in the
palette.
